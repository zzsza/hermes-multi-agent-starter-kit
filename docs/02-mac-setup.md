# Mac 설치 안내

처음에는 [SETUP.md](../SETUP.md)의 도구 설치와 대상 질문을 완료합니다. Codex, Tailscale, Aside와 Hermes가 이미 설치되었다고 가정하지 않습니다. 누락된 항목을 먼저 설치합니다.

설치 후 [프로필과 Slack 구축](08-reproduce-a-cx.md)을 진행합니다. 이 자료의 경로는 source 설치의 예시이며 새 환경의 전용 Python 경로를 확인해 사용합니다. 기존 default 프로필과 다른 서비스를 보존합니다.

main과 cx는 별도의 OAuth 로그인 승인을 사용합니다. 인증 파일을 복사해서 공유하지 않습니다. API fallback과 API 키를 추가하지 않습니다. 모델 목록과 보조 모델의 호환성은 해당 계정과 설치 버전에서 작은 실제 요청으로 확인합니다.

macOS의 게이트웨이는 프로필별 launchd 서비스로 설치합니다. 로그인 세션, 절전과 재부팅 후 복구는 대상 장치에서 직접 시험합니다. 앱과 서비스가 설치된 사실만으로 장기간 상주 운용을 검증했다고 표현하지 않습니다.

상태, 재시작과 중지 명령은 [운영 가이드](../OPERATIONS.md)를 따릅니다.
