# 구조와 설치 전 확인

이 자료는 이전 설치자의 계정과 운영 장소를 기본값으로 사용하지 않습니다. 새 컴퓨터의 시작점은 [SETUP.md](../SETUP.md)입니다.

main은 메인 직원 A, cx는 고객 문의 검토 직원입니다. 사람의 요청에 따라 A가 CX에게 확인할 수 있고, CX가 직접 받은 사람 요청에서도 조율 필요성을 판단해 A에게 보고할 수 있습니다. 결과는 처음 Slack 스레드에 남깁니다.

직원은 프로필과 Slack 앱으로 분리합니다. 영구 사용자 메모리는 초기 설정에서 끄고, 허용된 사용자와 채널만 받습니다. 한 처리의 재호출과 되돌리기를 코드에서 제한합니다. 정책이나 근거가 없으면 A가 지정 담당자를 태그합니다.

API fallback은 사용하지 않습니다. 고객 발송, 환불 실행, 데이터 수정과 파일 삭제 도구는 없습니다. 새로운 직원과 외부 이벤트는 별도 요구사항으로 추가합니다.

설치할 OS와 CPU, ChatGPT 계정과 플랜, 테스트 워크스페이스와 채널, 기존 앱 이전 여부, 요청 허용 사용자와 사람 조율 담당자를 확인해야 합니다. 현재 계정에서 목표 모델이 실제로 호출되는지도 확인합니다. 이전 개발 시험이 새 계정의 사용 권한을 보장하지 않습니다.

자세한 구축은 [설치 가이드](08-reproduce-a-cx.md), 변경은 [요구사항 변경](13-changing-requirements.md)을 따릅니다.
