설치 시점의 문서와 해당 CLI 도움말을 함께 확인합니다. 과거 검증 버전은 Hermes v0.13.0, source commit 8c6b0c9ecd, 전용 Python 3.11.13입니다. 새 설치 버전과 호환성이 같다고 가정하지 않습니다.

## 새 환경에서 기록할 항목

OS와 CPU, 설치 버전과 전용 Python, 도구별 설치와 로그인 상태, 프로필과 앱 연결, 실행 서비스와 시험 결과를 구분해 기록합니다. 사용자 이름, Slack ID와 개인 설치 상태는 배포 자료 대신 새 컴퓨터의 private 설치 기록에 둡니다.

인증값과 비밀번호, 로그인 코드, 쿠키와 세션 DB는 기록과 압축에 포함하지 않습니다. 새 환경 검증의 정답 기준은 [검증 가이드](10-live-verification.md)를 따릅니다.
