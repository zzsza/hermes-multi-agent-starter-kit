# 초기 파일럿에서 확인한 기술 사항

이 문서는 개인 환경 정보와 실제 Slack 식별자를 제거한 참고 기록입니다. 새 컴퓨터의 설치 완료나 로그인 상태를 의미하지 않습니다.

초기에는 CX 한 프로필의 Slack 멘션, 스레드와 DM 연결을 시험했습니다. 이후 A 시작 확인과 CX 시작 조율 보고를 추가했습니다. 현재 동작 범위는 [최신 구축 가이드](08-reproduce-a-cx.md)와 [CX 시작 조율](12-cx-first-coordination.md)을 따릅니다.

Slack 의존성이 빠진 source 설치, 매니페스트 편집기 중복 입력, 인증 복제와 새 로그인 구분, 봇 메시지 수신 제한, 스레드 응답 식별과 재호출 차단을 실제 구축 과정에서 확인했습니다. 자세한 문제와 해결은 [시행착오](09-troubleshooting.md)에 남겼습니다.

원래 개인 계정, 구독 상태, 워크스페이스, 채널과 테스트 스레드 링크는 이 배포본에 넣지 않습니다. 새 대상은 [처음 설치 질문](../SETUP.md)에서 확인합니다.
