# Hermes A와 CX 파일럿 안내 초안

운영자 검토용이며 아직 게시하지 않았습니다.

- 새 업무는 `@Hermes A 요청 내용`으로 시작해 주세요. 실제 멘션 목록에서 A를 선택합니다.
- 추가 정보와 수정 요청은 같은 댓글 스레드에 보내 주세요. 멘션 없는 새 채널 메시지에는 답하지 않습니다.
- CS 정보가 필요하면 A가 별도 CX를 부릅니다. 중간 확인과 최종 정리가 같은 스레드에 남습니다.
- CX에게 직접 요청한 건도 조율이 필요하면 CX가 A에게 보고합니다. 같은 스레드에서 진행합니다.
- 정책이 없거나 근거가 충돌해 판단할 수 없으면 담당자를 태그합니다. 담당자는 같은 스레드에 답해 주세요.
- 첫 파일럿은 운영자만 허용합니다. 팀원은 허용 목록 등록 후 사용할 수 있습니다.
- 실제 업무 프롬프트와 정책을 아직 받지 않아 환불 여부, 보상액과 주문 상태를 확정할 수 없습니다.
- 고객 발송, 환불 실행과 시스템 변경은 사람이 검토하고 직접 처리합니다.
- 실제 고객 개인정보, 비밀번호, API 키와 토큰을 입력하지 마세요.
- API fallback은 사용하지 않습니다. 구독 오류가 나면 운영자에게 알려 주세요.
- 실패가 나면 스레드 링크, 기대 결과와 실제 결과를 기록합니다.

정식 프로세스 스킬을 추가하면 `[환불]`, `[리포트]`처럼 정해진 접두어를 함께 안내합니다. 현재는 업무 스킬이 미등록이라 접두어 자체가 실행 기능을 만드는 것은 아닙니다.
